# 아이콘 이미지 안내

이 폴더에 다음 크기의 아이콘 이미지를 추가해주세요:

- `icon16.png` - 16x16 픽셀
- `icon48.png` - 48x48 픽셀
- `icon128.png` - 128x128 픽셀

## 아이콘 생성 방법

### 1. 온라인 툴 사용
- [Favicon Generator](https://favicon.io/)
- [IconsFlow](https://iconsflow.com/)

### 2. 디자인 툴 사용
- Figma, Sketch, Adobe Illustrator 등

### 3. 이모지 활용
간단하게 이모지를 PNG로 변환:
- 🔗 (링크 이모지)
- 📊 (차트 이모지)
- 🔍 (검색 이모지)

## 임시 아이콘
개발 중에는 아이콘 없이 테스트 가능합니다.
manifest.json에서 icons 섹션을 임시로 제거하거나,
간단한 색상 사각형 이미지를 사용할 수 있습니다.
